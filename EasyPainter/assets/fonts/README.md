# NotoSansCJK-Regular.ttc

ImGui 调参面板中文显示修复所需的字体 bundle(随仓库分发,避免运行期依赖系统字体路径)。

## 来源
- 源文件:`/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`(Debian 包 `fonts-noto-cjk`)
- 包版本:`1:20230817+repack1-3`(upstream 版本日期 20230817)
- 上游项目:https://github.com/notofonts/noto-cjk
- 完整许可/版权文本(Debian):`/usr/share/doc/fonts-noto-cjk/copyright`

## 用途
- 本文件是 TrueType Collection(TTC),内含 JP/KR/SC/TC/HK 五个变体。
- 应用使用 `FontNo = 2`,即 **Noto Sans CJK SC(简体中文)** 变体,覆盖 ImGui 界面全部简体中文字符且 0 缺失(Latin/ASCII 亦齐全)。
